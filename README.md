# WorkforceIQ

## Smart Workforce Scheduling System

Schedule smarter. Work better.

## About the Project

WorkforceIQ is a web-based workforce management and scheduling
system designed to manage employees, shifts, availability,
leave, rosters, holidays, approvals, conflicts and workforce
operations from one centralized platform.

## Features

- JWT Authentication
- Employee Self-Registration
- Role-Based Dashboards
- Employee Management
- Shift Management
- Availability Management
- Leave Management
- Roster Management
- Conflict Detection
- Replacement Suggestions
- Shift Swaps
- Holiday Management
- Policy Management
- Reports
- AI Assistant

## User Roles

### Admin
Administrative workforce management.

### Manager
Workforce operations and scheduling management.

### Employee
Personal roster, availability, leave and shift swap management.
